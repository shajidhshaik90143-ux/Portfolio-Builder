# Portfolio Builder v1.0

A strong frontend portfolio builder using HTML, CSS and vanilla JavaScript.

## Included
- Live portfolio preview
- Profile, skills, projects, experience and education editors
- Project reordering
- Responsive desktop/tablet/mobile preview
- Three portfolio layouts
- Accent color and font controls
- Dark/light editor toggle
- LocalStorage persistence
- JSON import/export
- Print / Save as PDF
- Completion progress indicator
- Responsive UI
- Sample portfolio data

## Run
1. Extract the ZIP.
2. Open the folder in VS Code.
3. Open `index.html` with Live Server, or double-click `index.html`.
4. Edit your portfolio in the left panel.

No backend or npm installation is required.

## Files
- `index.html` — application UI
- `assets/style.css` — styling and responsive layout
- `assets/app.js` — application logic
- `sample/portfolio.json` — sample import data
